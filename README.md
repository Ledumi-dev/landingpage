# Ledumi Landingpage – GitHub Pages

1. Den gesamten Inhalt dieses Ordners in das Root-Verzeichnis eines GitHub-Repositories hochladen.
2. In GitHub: Settings → Pages → Deploy from a branch → main → /(root).
3. Die veröffentlichte HTTPS-Adresse in Wix Studio über Embed & Social → Embed Site einfügen.

Wichtig: Das Startlistenformular zeigt aktuell nur einen visuellen Dankesstatus und speichert keine E-Mail-Adressen. Für echte Anmeldungen Wix Forms oder einen Newsletter-Dienst verwenden.
